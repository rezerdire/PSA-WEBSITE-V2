# AI project instructions

Before creating or changing any user interface in this project, read [`UI_GUIDELINES.md`](UI_GUIDELINES.md).

`UI_GUIDELINES.md` is the required project UI standard. Treat it as the basis for new features, UI refactors, and visual fixes. Reuse existing project components and patterns, preserve unrelated behavior, keep feature scope isolated, and verify the rendered result on desktop and mobile before claiming completion.
